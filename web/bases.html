Introduction

HTML est un langage pour décrire les Pages Web :

  • HTML signifie Hyper Text Markup Language
  • HTML n'est pas un langzge de programmation, il est un langage de balisage
  • Un langage de balisage est un ensemble de balises
  • Le langage HTML utilise des balises pour décrire des pages Web

Le but d'un navigateur web (Comme Internet explorer ou Firefox) est de lire les documents HTML et de les afficher sous forme de pages Web. Le navigateur n'affiche pas les balises HTML, mais utilise les balises pour interpreter le contenu de la page
