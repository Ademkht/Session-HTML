Introduction

HTML est un langage pour décrire les Pages Web :

  • HTML signifie Hyper Text Markup Language
  • HTML n'est pas un langzge de programmation, il est un langage de balisage
  • Un langage de balisage est un ensemble de balises
  • Le langage HTML utilise des balises pour décrire des pages Web

Le but d'un navigateur web (Comme Internet explorer ou Firefox) est de lire les documents HTML et de les afficher sous forme de pages Web. Le navigateur n'affiche pas les balises HTML, mais utilise les balises pour interpreter le contenu de la page

Exemples :

  • Le texte entre <html> et </html> décrit la page Web
  • Le texte entre <body> et </body> est le contenu de la page visible
  • Le texte entre <h1> et </h1> est affiché comme un titre de niveau 1
  • Le texte entre <p> et </p> est affiché comme un paragraphe

Les balises titres

Les titres sont définis avec les balises <h1> à <h6>


Utilisez les balises titres HTML pour les titres seulement. Ne pas utiliser les balises titres pour rendre le texte GROS ou gras. Les moteurs de recherche utilisent bos balises titres pour indexer la structure et le contenu de vos pages Web. Il est important de les utiliser pour structurer le document. Les balises H1 devraient être utilisées comme rubriques principales, suivies de vbalises H2, puis les balises H3 moins importantes, et ainsi de suite.

Les paragraphes

Les paragraphes sont définies avec la balise <p>.

La balise <br> insère un saut de ligne

La balise <hr> insère une ligne horizontale
